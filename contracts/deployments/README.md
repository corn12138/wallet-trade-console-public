# Deployments

This directory stores contract deployment records for different networks.

## Files

- `sepolia.json` - Sepolia testnet deployment
- `mainnet.json` - Ethereum mainnet deployment (when deployed)

## Structure

```json
{
  "network": "sepolia",
  "chainId": 11155111,
  "deployer": "0x...",
  "deployedAt": "2025-01-01T00:00:00.000Z",
  "contracts": {
    "factory": "0x...",
    "router": "0x...",
    "weth": "0x...",
    "tokenA": "0x...",
    "tokenB": "0x...",
    "pair": "0x..."
  }
}
```

## Usage

These files are automatically generated by deployment scripts:

```bash
# Deploy to Sepolia - creates/updates sepolia.json
pnpm deploy:sepolia

# Add liquidity - updates pair address in sepolia.json
pnpm add-liquidity:sepolia
```

## Note

Even if you lose these files, you can always find your deployed contracts by:
1. Checking your deployer wallet's transaction history on Etherscan
2. Looking at the contract creation transactions
